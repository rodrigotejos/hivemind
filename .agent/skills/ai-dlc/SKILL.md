# AI-Driven Development Life Cycle (AI-DLC) Workflow

When the user invokes AI-DLC or asks to develop software using AI-DLC, read and follow the core workflow specification:

- Core Workflow: [core-workflow.md](../../.aidlc/aidlc-rules/aws-aidlc-rules/core-workflow.md)
- Rule Details: `.aidlc/aidlc-rules/aws-aidlc-rule-details/`

## Key Phases
1. **Inception Phase**: Workspace detection, reverse engineering, requirements analysis, user stories, application design, workflow planning.
2. **Construction Phase**: Functional design, NFR requirements/design, infrastructure design, code generation, build & test.
3. **Operations Phase**: Operations readiness and deployment instructions.
